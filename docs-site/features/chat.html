Research Chat

Панель «Спросить агента» в ResearcherOS отвечает на вопросы по выбранному проекту. После отправки вопроса локальный агент запускается автоматически; ответ и ход работы видны в приложении.

Слот для картинки или видео Положите файл в media/chat-hero.png (или .jpg / .webp / .mp4 / .webm).

Как работает

  1. Агент сначала сопоставляет вопрос с выводами в research.json.
  2. Если нужны детали, которых нет в выводах, он открывает связанные отчёты экспериментов.
  3. Если проект пока не содержит ответа, агент говорит об этом прямо.
  4. Готовый ответ возвращается в ту же панель чата.

ResearcherOS запускает установленный Cursor CLI в фоновом режиме. Если он недоступен, приложение пробует локальный Codex CLI или Claude Code CLI. Отдельный Inbox-чат и ключ Cursor API для вопросов не требуются.

Как человек работает в интерфейсе

  1. Откройте проект и панель «Спросить агента».
  2. Напишите вопрос и нажмите «Отправить».
  3. Вкладка «Чат» покажет состояние обработки и ответ. Вкладка «Работа агента» покажет реплики агента и вызовы инструментов; основной экран останется на месте.

Вопрос может учитывать выбранный метод или узел, но агенту доступна база выводов всего проекта.

Какие сценарии для агента подключаются

Сценарий Роль
koi-agent-chat Правила ответа: сначала выводы проекта, затем нужные детали отчёта.
koi-done-research Пополняет базу выводов после завершения карточки.
koi-knowledge-curator Курируемые заметки как дополнительный контекст.

Как устроено технически

Вопрос сохраняется в .run/agent-chat-queue.json. Сервер запускает локальный CLI в фоне, пишет события в журнал вопроса и сохраняет готовый ответ в очередь. Панель обновляет состояние через API. Код находится в koi/agent_chat/ и web/app.js.

Чат не меняет дерево проекта сам по себе. Качество ответа зависит от выводов и отчётов, которые уже есть в проекте.
