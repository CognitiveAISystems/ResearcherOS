Установка на Mac

Клонируйте репозиторий и запустите установщик двойным щелчком. Приложение появится в папке «Программы» вашего пользователя, ярлык — на рабочем столе.

Установка

  1. Клонируйте репозиторий 
    git clone https://github.com/CognitiveAISystems/ResearcherOS.git ReseachOS

    Если Git ещё не установлен, macOS может предложить установить инструменты разработчика. Дождитесь установки и повторите команду.

  2. Откройте установщик

    Откройте папку ReseachOS в Finder и дважды щёлкните по файлу «Установить ResearcherOS.command».

  3. Дождитесь окончания установки

    Откроется окно Терминала с этапами установки. Понадобится интернет: установщик загрузит инструменты и зависимости, соберёт приложение и поместит его в ~/Applications/ResearcherOS.app. Homebrew и пароль администратора не нужны.

  4. Откройте ResearcherOS

    После сообщения об окончании установки откройте приложение через ярлык на рабочем столе. При первом запуске выберите папку для исследовательских проектов. При следующих запусках сервер запускается вместе с приложением.

Разрешение macOS

Если macOS блокирует запуск из-за неизвестного разработчика, откройте «Системные настройки → Конфиденциальность и безопасность» и разрешите запуск. Приложение собирается на вашем Mac; сертификат разработчика Apple не используется.

Первый проект

Создайте проект кнопкой «+ Новый проект» или подключите существующий код. Для работы агента отдельно установите поддерживаемую программу агента для командной строки и войдите в свою учётную запись.

Обновление

Закройте ResearcherOS, выполните git pull в папке репозитория и снова запустите установщик. Настройки и исследовательские проекты сохранятся.

Если установка прервалась

Установщик покажет путь к журналу в .run/logs/. После устранения причины его можно запустить повторно. При обновлении прежнее приложение сохраняется до окончания сборки и копирования новой версии.

Сборка предусмотрена для Apple Silicon и Intel. Проверка на отдельном чистом Mac перед публичным выпуском ещё требуется.
