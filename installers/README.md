# Установщики ResearcherOS

Клонируйте репозиторий с установленным [Git LFS](https://git-lfs.com/), затем запустите файл для своей системы.

| Система | Файл |
|---------|------|
| macOS | [Установить ResearcherOS.command](Установить%20ResearcherOS.command) |
| Windows | [ResearcherOS Setup 0.1.0.exe](ResearcherOS%20Setup%200.1.0.exe) |
| Linux | [ResearcherOS-0.1.0.AppImage](ResearcherOS-0.1.0.AppImage) |

На macOS установщик собирает приложение из исходников в этом клоне репозитория. Сборка Windows получена из [GitHub Actions](https://github.com/CognitiveAISystems/ResearcherOS/actions/runs/38227118667) и прошла автоматическую проверку установки и запуска.

Linux AppImage пересобран на Pop!_OS 22.04 (x86_64, glibc 2.35). На этой системе 26 октября 2026 года проверены запуск с включённым sandbox, первоначальная настройка через системный выбор папки исследований и повторный запуск с сохранёнными настройками. Python и Node.js пользователю устанавливать не нужно; для подключения Git-репозиториев нужен Git. Обновление поверх прежней установки ещё требует проверки.

Если `.exe` или `.AppImage` не запускается и вместо приложения скачался маленький текстовый файл, выполните `git lfs install` и `git lfs pull` из корня репозитория.

[Подробная установка и подключение проектов](../README.md#установка).
