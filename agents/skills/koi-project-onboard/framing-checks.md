# Проверка постановки при создании дерева

Актуальный сценарий и формат брифа: [SKILL.md](SKILL.md).
Типы узлов и связей: [доменная модель](../../../docs/domain-model.md).

Классифицируй по неопределённости способа решения, а не по слову «разработка».
Проверь смысл родителя и ребёнка, допустимость связи, один узел каждого типа
и конкретный метод для канбана. Гипотеза — связь, причина — описание.
Уточняй только структурные варианты; не проводи интервью по протоколу прогона.
