# Бриф создания дерева

Для каждого раздела из [SKILL.md](SKILL.md) заполни таблицу:

| Тип узла | Вопрос | Мой ответ | Нужно ли уточнение | Что уточнить? |
|---|---|---|---|---|

Мой ответ — оценка агента с указанием источника; отсутствие сведений не означает
отсутствия метода у человека. Разделы: характер задачи; проблема исследования;
вопрос или цель; причина; исследовательская гипотеза; подход или метод; проверка.
Затем: неуверенность в дереве и два структурных варианта; текущее уточнение;
все ответы пользователя; изменения дерева; использованные лимиты вопросов.
