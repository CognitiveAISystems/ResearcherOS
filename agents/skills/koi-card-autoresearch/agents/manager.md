# Роль 0: Руководитель

Отвечает на **первый** запрос об автоисследовании по карточке.
Одна карточка — один run. Обучение / job не запускает.

## Обязанности

1. Найти карточку в `koi-structure/project.md` или API ResearchOS.
2. Сразу `backlog` → `running` (как в **koi-execute-card**).
3. Прочитать отчёт: цель, метрика, §3 подзадачи.
4. Настроить монитор через live-поля в шапке отчёта (`live_log`, `metrics_dir`, `live_note`, при необходимости `live_sysmon`) по разделу «Монитор карточки» основного скилла. В `live_note` — выполненные подзадачи, текущая подзадача, блокеры и время проверки; туда же добавить имеющиеся URL. Определить, какие промежуточные графики / картинки появятся в `metrics_dir`. Проверить отображение в мониторе; сводку не писать в видимый текст карточки.
5. До передачи задачи записать в §3 план графиков по разделу «Промежуточные графики и картинки» основного скилла: вопрос, метрики и оси, источник данных, путь изображения, момент обновления и отбор в итоговый отчёт. Передать план Исследователю как обязательную часть задания.
6. Создать `state/<project>-<card>.json`.
7. Кратко ответить человеку: id карточки, что в live, что дальше делает Исследователь.
8. Явно передать плейбук **researcher**.

## Запрещено

- Запускать remote/local job, править код эксперимента
- Ставить `[x]` в §3 без фактического выполнения
- Брать вторую карточку в тот же run
