Установка на Mac

Скачайте готовое приложение для своего Mac или установите его скриптом из исходников.

Готовое приложение

  1. Откройте стабильный релиз. Для A/B-тестирования выберите выпуск beta-test с отметкой Pre-release на странице релизов.
  2. Скачайте DMG arm64 для Apple Silicon (M1 и новее) или x64 для Intel.
  3. Откройте DMG и перенесите ResearcherOS.app в папку Applications. Если нет прав на общую папку, используйте ~/Applications.
  4. Запустите приложение и пройдите первоначальную настройку.

Для установки из DMG не нужны клонирование репозитория, Python или Node.js. Для подключения исследовательских репозиториев нужен Git.

Альтернатива: установка скриптом

  1. Клонируйте репозиторий 
    git clone https://github.com/CognitiveAISystems/ResearcherOS.git ReseachOS

    Если Git ещё не установлен, macOS может предложить установить инструменты разработчика. Дождитесь установки и повторите команду.

  2. Откройте установщик

    Откройте папку ReseachOS/installers в Finder и дважды щёлкните по файлу «Установить ResearcherOS.command».

  3. Дождитесь окончания установки

    Откроется окно Терминала с этапами установки. Понадобится интернет: установщик загрузит инструменты и зависимости, соберёт приложение и поместит его в ~/Applications/ResearcherOS.app. Homebrew и пароль администратора не нужны.

  4. Настройте ResearcherOS

    Установщик откроет приложение с мастером настройки. Сначала можно указать готовую папку tree. Если её нет, мастер предложит репозиторий с исследовательской веткой, затем — новый репозиторий с кодом. Материалы подключённого репозитория хранятся в ~/Documents/tree/<проект>/koi-structure/, отдельно от кода. Повторный запуск установщика снова откроет мастер. Ранее подключённые проекты сохранятся. При следующих обычных запусках сервер запускается вместе с приложением.

Разрешение macOS

Если macOS блокирует запуск из-за неизвестного разработчика, откройте «Системные настройки → Конфиденциальность и безопасность» и разрешите запуск. DMG выпускаются с локальной ad-hoc-подписью без сертификата Developer ID и notarization Apple. Скриптовая установка тоже не требует сертификата.

Первый проект

Создайте проект кнопкой «+ Новый проект» или подключите существующий код. Для работы агента отдельно установите поддерживаемую программу агента для командной строки и войдите в свою учётную запись.

Обновление

При установке из DMG закройте ResearcherOS и замените приложение новой версией из того же канала. Настройки и исследовательские данные хранятся отдельно; обновление поверх прежней установки ещё требует ручной проверки.

При установке скриптом закройте ResearcherOS, выполните git pull в папке репозитория и снова запустите установщик. Настройки и исследовательские проекты сохранятся.

Если установка прервалась

Установщик покажет путь к журналу в .run/logs/. После устранения причины его можно запустить повторно. При обновлении прежнее приложение сохраняется до окончания сборки и копирования новой версии.

CI проверяет установку из DMG и запуск на Apple Silicon и Intel. Проверка Gatekeeper после скачивания через браузер на отдельном Mac пока не выполнена. Более старые версии macOS отдельно не проверялись.
